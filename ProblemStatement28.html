1. The Challenge

Access to reliable health information remains a critical challenge globally. People frequently search for symptoms online, encounter misinformation, and either ignore serious conditions or unnecessarily panic about minor ones. Traditional symptom checkers are either static flowcharts with no intelligence, or they provide dangerous self-diagnosis suggestions without proper medical caveats.

An Agentic AI Health Symptom Checker addresses this gap by helping users understand their health conditions by analyzing symptoms in natural language and providing probable causes, preventive advice, and care recommendations — all sourced from verified medical databases.

The challenge specifically requires:

  • Retrieval of verified medical data from trusted sources like WHO, CDC, NIH, and government health portals
  • Processing of natural language symptom descriptions (e.g., "I have a sore throat and fever")
  • Providing possible conditions, urgency level, home remedies, and when to consult a doctor
  • Supporting multi-language interaction
  • Avoiding self-diagnosis risks through educational and referral-based suggestions
  • Mandatory use of IBM Cloud Lite services / IBM Granite

2. Proposed Solution

The proposed solution is an Agentic AI Health Symptom Checker built using Flask, IBM watsonx.ai, and IBM Granite 13B Instruct model, following a ReAct (Reason + Act) agent architecture to analyze health symptoms intelligently.

Agent Architecture — ReAct Tool-Use Pipeline

When a user submits symptoms, the agent executes 4 tools in sequence before calling IBM Granite:

User Input (natural language) ↓ [INPUT GUARDRAILS] → Sanitize · Relevance · Injection Guard · Rate Limit · PII Redact ↓ Tool 1: detect_language() → Identify language (EN/HI/ES/FR/ZH/AR/PT) Tool 2: check_emergency() → Scan 20+ red-flag keywords → bool Tool 3: lookup_symptoms() → Search WHO/CDC/NIH database → matched entries Tool 4: assess_urgency() → Low / Moderate / High / Emergency ↓ IBM Granite 13B Instruct v2 → Generate enriched educational health response ↓ [OUTPUT GUARDRAILS] → Diagnosis Filter · Prescription Filter · Disclaimer · Hedging · Emergency Escalation ↓ Structured JSON Response → Chat UI

3. Urgency Classification System

Every symptom query is automatically classified into one of four urgency levels:

🟢 Low — Monitor at home 🟡 Moderate — See doctor within 48h 🔴 High — Seek prompt medical care 🚨 Emergency — Call 911/112/108 NOW

4. Safety Guardrails (10 Layers)

Input Guardrails — Applied before the AI agent runs

#GuardrailWhat it does
1Input SanitizationStrips HTML tags, control characters, normalizes whitespace; blocks inputs under 3 characters
2Topic RelevanceBlocks off-topic queries: code requests, finance, politics, recipes, entertainment
3Prompt Injection GuardDetects "ignore instructions", "act as", "jailbreak", DAN mode, <|system|> injection
4Rate LimitingMaximum 20 requests per minute per session to prevent abuse
5PII RedactionDetects and redacts emails, phone numbers, SSN, Aadhaar, DOB, credit cards (non-blocking)

Output Guardrails — Applied after IBM Granite generates a response

#GuardrailWhat it does
6Diagnosis Language FilterRewrites "you have diabetes" → "your symptoms may suggest..." to prevent false diagnosis
7Prescription FilterRemoves specific drug dosage recommendations (e.g., "take 500mg") from AI output
8Disclaimer EnforcementGuarantees the medical disclaimer is always appended to every single response
9Hedging Language CheckEnsures uncertainty language ("may", "consult", "suggest") is present in every response
10Emergency EscalationIf emergency detected but 911/112/108 numbers are missing from response, injects them

9. How IBM Granite is Used

IBM Granite 13B Instruct v2 is called via the ibm-watsonx-ai Python SDK using the following configuration:

  • Model ID: ibm/granite-13b-instruct-v2
  • Temperature: 0.3 (low — factual, consistent responses)
  • Max new tokens: 1024
  • Top-p: 0.9
  • Repetition penalty: 1.1
  • Prompt format: Granite instruction format with <|system|>, <|user|>, <|assistant|> tags
  • Prompt includes: Verified DB context, matched conditions, urgency level, language hint, safety instructions
⚠️ Medical Disclaimer: This AI Health Symptom Checker provides educational information only and does NOT constitute medical advice, diagnosis, or treatment. Always consult a qualified healthcare professional for medical concerns. In case of emergency, call your local emergency services immediately (911 / 112 / 108).
